# 镜花水月（JHSY）

原生 Android 自动换壁纸应用。

从 **Wallhaven** 拉取壁纸，支持关键词 / 跃迁模式、多密钥轮换、网络与本地双兜底、桌面与锁屏隔离、省电休眠、超级服务保活、HTTP/SOCKS5 代理与 Root 超级代理（仅本应用）等。

| 项目 | 值 |
|------|-----|
| 应用名 | 镜花水月 |
| 包名 | `com.kers.killove.jhsy` |
| 当前版本 | **v3.1.14**（versionCode `3114`） |
| 最低系统 | Android 8.0（API 26） |
| 目标 SDK | 35 |
| 仓库 | https://github.com/kers701/wallpaper_app |

> 与旧包名（如 `com.kers701.wallpaperc`）**不能覆盖安装**，数据不互通。

> **文档约定**：每次功能迭代同步更新本 README，以与源码行为一致。

## 功能概览

### 更换与调度

- 立即更换 / 按间隔自动更换（5～180 分钟）
- WorkManager 后台调度；可选**强制前台服务**（通知栏常驻）
- 息屏跳过；亮屏后可恢复判断（`ScreenOnReceiver`）
- **省电模式**：电量低于设定阈值（5～50%）时休眠；**充电时忽略**；电量恢复后继续
- **省流量**：按当日缓存增量抬高间隔
- 开机广播恢复任务
- 申请忽略电池优化、三星等机型自启动提示

### 超级服务（独立进程保活）

- 更换服务可运行在独立进程 `:svc`
- 可选 Root / 无障碍保活
- UI 被划掉后，服务进程仍可能继续（视系统与权限而定）

### 壁纸来源与兜底链

```
强制本地？
  → 本地目录随机选图
否则
  → Wallhaven（关键词 / 跃迁词 + 多 Key 轮换）
  → 失败且开启网络兜底 → 自定义兜底 API（可多行多个，依次尝试）
  → 仍失败且开启本地兜底 → 本地目录 / 缓存
```

- **Wallhaven**：纯度、类别（真人 / 动漫 / 轮换）、分辨率（设备自适应 / 1.5K / 自定义）
- **方向过滤**（三选一）：无过滤 / 横屏过滤（仅竖屏）/ 竖屏过滤（仅横屏）
- **多 API Key**：每行一个，请求失败自动轮换
- **兜底 API**：支持 `{width}` `{height}`；响应可为直接图片、一行 URL 或含 path/url/image 的 JSON；多行多个 URL
- **本地兜底**：默认 `files/local_fallback/`，可填公共目录绝对路径

### 关键词与跃迁

- 本地多行关键词；可选远程 txt 导入（覆盖 / 合并）
- **跃迁模式**：Wallhaven **成功**后，用该图标签**覆盖**写入跃迁列表（与正常关键词分离）
- **排除本次搜索词**：写入跃迁列表时自动忽略与「本次使用关键词」相同的标签
- 跃迁开启且列表非空时，搜索从跃迁列表取词；否则用正常列表
- **关键词翻译**（仅展示 / 日志，**不改**实际搜索词）：谷歌 / 微软 / 腾讯，可配 API 密钥

### 桌面与锁屏

- 目标：仅桌面 / 仅锁屏 / 桌面+锁屏
- **桌面锁屏隔离**：开启后下载两次、设置两次（先桌面再锁屏）
- **铺满方式**（对齐 Windows）：填充 / 适应 / 拉伸

### 网络代理

- **普通代理**：HTTP / SOCKS5，支持订阅链接导入多节点、节点选择、自动测速（可强制中断）
- **回退链**：超级代理（若启用且可用）→ 普通代理 → 系统网络
- **超级代理（仅本应用）**（需 Root）：
  - 通过文件选择器导入内核（如 mihomo）与配置到应用私有目录，并修正权限
  - 监听 `127.0.0.1:本地端口`（默认 17890），**不启用 TUN / 全局劫持**
  - 配置优先级：用户配置文件 > 订阅链接自动生成 Clash 默认配置
  - 关闭超级代理或关闭代理时自动杀掉内核；启动前先杀旧进程，避免双开
  - 无 Root 时不显示超级代理配置项；须先启用代理才能启用超级代理

### 界面与安全

- 半透明主题：遮罩透明度、卡片透明度可调；板块样式
- **PIN 锁定**：锁定后 API 密钥、关键词、兜底 API、翻译密钥、**配置备份** 等敏感项不可见
- PIN 存哈希；进程重启后需重新解锁
- 选项关闭时仅显示开关，打开后再展开详细配置

### 配置备份 / 恢复

- **备份内容**：除 **PIN**（`pinHash` / `pinEnabled`）外的**全部**配置，包括：
  - 调度、纯度、类别、分辨率、方向、铺满、省电、省流量、超级服务
  - API 密钥、关键词 / 跃迁词、远程关键词地址、黑名单
  - 网络 / 本地兜底、云备份账号路径、定位避让与避让点
  - 代理类型/地址、订阅、节点列表、选中节点、测速间隔
  - 超级代理开关、订阅 URL、参数、本地端口、本机路径字符串
  - UI 主题、翻译密钥、软件背景等
- **恢复规则**：始终**保留本机 PIN**，不会从备份写入 PIN
- **方式**：
  1. 备份到应用目录（并复制 JSON 到剪贴板）
  2. 备份 / 恢复公共目录文件（SAF）
  3. 粘贴 JSON 恢复
  4. **从远程 URL 导入**：填写可直链访问的备份 JSON 地址（http/https），拉取后合并恢复
- **注意**：超级代理「内核路径 / 配置路径」是本机私有目录路径，换机或重装后需重新在应用内选择文件导入；远程配置中的路径在新设备上可能无效，可改用订阅 URL 自动生成配置

备份 JSON 字段 `version` 当前为 `2`；旧版 `version: 1` 仍可导入（缺省字段用本机当前值）。

| 模式 | 说明 |
|------|------|
| Auto | 系统壁纸优先，失败则莫奈取色 |

| Monet | 莫奈取色 |

- 更换记录保留最近约 **77** 条
- 可清理 `wallpapers` 下载缓存

## 本地兜底目录

- 默认：App 私有目录 `files/local_fallback/`（随应用卸载清除）
- 可填写绝对路径，例如：`/storage/emulated/0/Pictures/Wallpapers`
- 支持：`jpg` / `jpeg` / `png` / `webp` / `bmp`

## 远程关键词 txt 格式

```
# 注释行
landscape
anime girl
cyberpunk
```

每行一个词，`#` 开头为注释。

## 远程配置 JSON

将「备份到应用目录 / 公共目录」得到的 `jhsy_config_backup.json` 托管到任意可直链下载的地址，在设置 → 配置备份 / 恢复 → **从远程 URL 导入配置** 中填写该 URL 即可。

- 须返回 JSON 对象（以 `{` 开头）
- 不会覆盖本机 PIN
- 建议使用 HTTPS

## 兜底 API 示例

```
https://example.com/random?w={width}&h={height}
https://backup.example.com/pic
```

## 环境要求

- Android Studio Ladybug / Koala 或更新（AGP 8.7+）
- JDK 17、Android SDK 35
- 真机或模拟器 API 26+

## 构建

```bash
./gradlew assembleDebug
# 输出：app/build/outputs/apk/debug/app-debug.apk

./gradlew assembleRelease
# 需自行配置签名
```

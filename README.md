# MiroFlweat

原生 Android **自动换壁纸**应用。

从 [Wallhaven](https://wallhaven.cc/) 拉取壁纸，支持关键词 / 跃迁、多 Key 轮换、网络与本地双兜底、桌面锁屏隔离、省电与省流量、定位避让、代理与加速、超级服务保活等。

| 项目 | 值 |
|------|-----|
| 应用显示名 | **MiroFlweat** |
| 包名 | `com.kers.killove.jhsy`（不变） |
| 最低系统 | Android 8.0（API 26） |
| 目标 SDK | 35 |
| 仓库 | https://github.com/kers701/wallpaper_app |

命名由「镜花水月」相关英译组合而来；包名与内部标识不变。  
**版本更新记录** → [CHANGELOG.md](CHANGELOG.md)　|　图标 → [README_ICON.md](README_ICON.md)

应用内 **使用说明**（首页入口）与本文互补，偏操作向导。

## 壁纸拉取链路

```
强制本地模式？
  → 仅从本地目录（及可选下载缓存）选图
否则
  → Wallhaven（关键词 / 跃迁词 + 多 Key）
  → 失败且开启「网络兜底」→ 自定义兜底 API（可多行依次试）
  → 仍失败且开启「本地兜底」→ 本地目录 / 历史缓存
```

自动更换还会受：**息屏跳过、省电休眠、省流量限制、应用黑名单、定位避让（绿色/极限）** 等规则影响。手动「立即更换」通常更宽松（仍可能受部分规则约束）。

## 配置项说明（按设置页）

以下选项均可在应用 **配置** 页找到。保存后生效；部分项需对应系统权限。

### 1. 基础

| 选项 | 可选值 / 范围 | 说明 |
|------|----------------|------|
| **更换间隔** | 约 5～180 分钟（滑条） | 两次自动更换的最短间隔。间隔较短时建议开前台服务 |
| **启用纯度筛选** | 开 / 关 | **关**：每次在全部合法纯度组合中完全随机。**开**：用下方三档组合请求 Wallhaven |
| **保守级** | 选中 / 取消 | 对应 Wallhaven SFW（代码位 `1xx`） |
| **模糊级** | 选中 / 取消 | 对应 Sketchy（`x1x`） |
| **限制级** | 选中 / 取消 | 对应 NSFW（`xx1`）；**未配置 API Key 时不可选** |
| **纯度组合示例** | `010` 仅模糊；`001` 仅限制；`011` 模糊+限制；`101` 保守+限制；`110` 保守+模糊；`111` 全部 | 多选按位合成三比特代码 |
| **类别** | 仅真人 / 仅动漫 / 真人·动漫轮换 | Wallhaven 分类过滤 |
| **设置目标** | 仅桌面 / 仅锁屏 / 桌面+锁屏 | 系统壁纸写入目标 |
| **分辨率** | 设备自适应 / 最低约 1500×1500 / 自定义 | 自定义时可填最低宽、高 |
| **强制前台服务** | 开 / 关 | 通知栏常驻，利于保活；划掉后视系统与超级服务是否自启 |
| **息屏时跳过** | 开 / 关 | 灭屏不换；亮屏后再判断是否到期 |
| **忽略电池优化** | 跳转系统页 | 建议允许，减少被杀进程 |
| **加速模式** | 开 / 关（与「网络代理」互斥） | 经内置/配置的中转节点拉取；开启前须阅读并同意安全与隐私声明；可选远程节点 JSON 地址 |
| **方向过滤** | 无过滤 / 横屏过滤（仅竖屏）/ 竖屏过滤（仅横屏） | 过滤横图或竖图 |
| **壁纸铺满方式** | 填充 / 适应 / 居中 / 拉伸 | 填充=等比铺满裁边；适应=完整显示可留边；居中=原图居中；拉伸=变形铺满。修改后可用当前图重设而不重新下载 |
| **桌面锁屏隔离** | 开 / 关 | 开：一轮内两次下载与设置（先桌面后锁屏），关键词逻辑可分离 |
| **省电模式** | 开 / 关 | 未充电且电量低于阈值时休眠不自动换；充电忽略 |
| **省电电量阈值** | 约 5～50% | 仅省电开启时有效 |
| **省流量模式** | 开 / 关 | 按当日写入壁纸缓存的字节量：达档提高自动间隔；很高时当日可停自动换（手动仍可用） |

**纯度与运行模式（通知栏切换，可覆盖配置页勾选）：**

| 模式 | 纯度策略 |
|------|----------|
| 普通 | 遵循配置：未开筛选则随机；开启则用勾选组合 |
| 健康 | **锁定仅模糊级**（`010`） |
| 心跳 | **锁定模糊级+限制级**（`011`） |
| 绿色（定位避让区内且开启绿色） | **锁定保守级+模糊级**（`110`）；配置页纯度选择只读提示「已被接管」 |

### 3. 关键词

| 选项 | 说明 |
|------|------|
| **启用关键词搜索** | 关则可不带关键词检索（视实现与 API） |
| **关键词列表** | 每行一个；轮换使用 |
| **远程关键词 URL** | 拉取 txt 后覆盖或合并（以界面操作为准） |
| **跃迁模式** | 开：Wallhaven **成功**后用该图标签**覆盖**写入跃迁列表；列表非空时搜索优先用跃迁词 |
| **跃迁列表 / 索引** | 与普通关键词分离；首页可预览「下次将用」 |
| **湮灭等相关** | 若界面提供：用过的跃迁词可写入缓存并在提取时排除（以当前版本界面为准） |

---

### 4. 兜底策略

| 选项 | 说明 |
|------|------|
| **网络兜底** | Wallhaven 失败后走自定义兜底 API |
| **兜底 API** | 多行 URL；支持 `{width}` `{height}`；响应可为图片流、单行 URL 或含 path/url 的 JSON |
| **本地兜底** | 网络路径仍失败时从本地目录选图 |
| **强制本地模式** | 不访问网络，只从本地（及可选缓存）换壁纸 |
| **本地兜底目录** | 默认应用私有 `files/local_fallback/`；可填公共绝对路径 |
| **本地兜底也使用下载缓存** | 从已下载的 `wallpapers` 缓存选图 |
| **跳过最新 N 张缓存** | 避免总用刚下的几张；N 可调 |

---

### 5. 网络代理

| 选项 | 可选值 / 说明 |
|------|----------------|
| **启用代理** | 与加速模式互斥；开启且配置有效时本应用请求走代理 |
| **代理类型** | **HTTP** / **SOCKS5** |
| **服务器 / 端口 / 用户名 / 密码** | 手动单节点 |
| **订阅链接或节点列表** | URL 或 `socks5://host:port#名` 等，可导入解析 |
| **节点选择** | **手动选择** / **自动优选**（测速） |
| **自动测速间隔** | 约 5～180 分钟（自动优选时） |
| **超级代理（Root）** | 仅本应用：Root 启动自定义内核，监听本机端口；**非**全局 TUN |
| **内核文件 / 配置文件 / 订阅 / 启动参数 / 本地 SOCKS 端口** | 配置优先：已有配置文件 > 订阅生成；端口默认如 17890；可启动/停止内核 |

---

### 6. 超级服务（独立进程保活）

| 选项 | 说明 |
|------|------|
| **超级服务** | 更换相关逻辑可运行在独立进程 `:svc`，UI 划掉后仍可能继续 |
| **无障碍 / Root 保活** | 按机型与权限尝试保活；需在系统中授权 |
| 仍建议 | 忽略电池优化、自启动、后台运行（各厂商路径不同） |

---

### 7. 应用黑名单

| 选项 | 说明 |
|------|------|
| **黑名单包名列表** | 这些应用在**前台**时休眠、不自动换壁纸 |
| **管理黑名单** | 次级页：已选列表 + 搜索已安装应用 |
| 权限 | 需要「使用情况访问」类权限 |
| 通知 | 可将当前前台应用加入黑名单（通常需确认） |

---

### 8. 定位避让

| 选项 | 说明 |
|------|------|
| **启用定位避让** | 在避让点半径内触发策略 |
| **高德 Web 服务 Key** | 地点搜索、逆地理；PIN 锁定时可能隐藏 |
| **触发半径** | 约 5～500 米（管理页滑条） |
| **避让点列表** | 搜索添加、当前位置添加、自定义标签或自动地名 |
| **绿色模式** | 区内锁定纯度「保守级+模糊级」 |
| **极限回退** | 区内**仅**本地文件换壁纸 |
| 离开所有点半径后 | 恢复进入前的纯度与「强制本地」等状态 |
| 权限 | Android 10+ 建议定位「始终允许」，否则后台难判定 |

### 12. PIN 锁定

| 选项 | 说明 |
|------|------|
| **启用 PIN** | 锁定后密钥、关键词、兜底 API、翻译密钥、部分备份入口等敏感项不可见 |
| **设置 / 修改 / 解锁** | PIN 存哈希；进程重启后通常需重新解锁 |

### 13. 配置备份 / 恢复

| 选项 | 说明 |
|------|------|
| **导出配置** | 生成 JSON（一般**不含** PIN） |
| **从文件恢复 / 粘贴 JSON** | 恢复后本机 PIN 策略以当前实现为准（通常保留本机 PIN） |
| **远程配置 URL** | 若界面提供：从 URL 拉取配置 |

说明：历史版本曾出现云备份（WebDAV 等），**是否保留以当前设置页为准**；主路径为本地导出/导入。

## 格式与路径约定

### 本地兜底目录

- 默认：`files/local_fallback/`（随卸载清除）
- 可填：`/storage/emulated/0/Pictures/Wallpapers` 等
- 格式：`jpg` / `jpeg` / `png` / `webp` / `bmp`

### 远程关键词 txt

```
# 注释
landscape
anime girl
```

### 兜底 API 示例

```
https://example.com/random?w={width}&h={height}
https://backup.example.com/pic
```

# MiroFlweat

原生 Android 自动换壁纸应用。

从 **Wallhaven** 拉取壁纸，支持关键词 / 跃迁模式、多密钥轮换、网络与本地双兜底、桌面与锁屏隔离、省电休眠、超级服务保活等。

| 项目 | 值 |
|------|-----|
| 应用名 | **MiroFlweat** |
| 包名 | `com.kers.killove.jhsy`（不变） |
| 当前版本 | **v3.2.2**（versionCode `3202`） |
| 最低系统 | Android 8.0（API 26） |
| 目标 SDK | 35 |
| 仓库 | https://github.com/kers701/wallpaper_app |

命名说明：显示名由「镜花水月」英译经特别组合拆解得到；包名与内部标识仍用原体系。

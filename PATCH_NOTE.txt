增量补丁：虚妄关键词看板 SQLite 乱码（不推送仓库）

现象：
虚妄模式显示「全员升华」，点击展开却出现 SQLite format 3 / CREATE TABLE 等乱码。

原因：
illusion_last_round.txt 被读成了含 SQLite 库头的二进制/脏数据；
概览卡片在列表非空时可展开，未与「全员升华」状态互斥。

修复：
1. IllusionStore：检测 SQLite 魔数则清空；只接受干净关键词行；meta=none 时强制空列表；原子写入
2. AnnihilationStore：同样做脏数据过滤（防止湮灭看板同类问题）
3. Home/Overview：仅在「有本轮记录且非全员升华且列表非空」时允许展开

覆盖路径：
app/src/main/java/com/kers/killove/jhsy/util/IllusionStore.kt
app/src/main/java/com/kers/killove/jhsy/util/AnnihilationStore.kt
app/src/main/java/com/kers/killove/jhsy/ui/screens/HomeScreen.kt
app/src/main/java/com/kers/killove/jhsy/ui/screens/OverviewScreen.kt

说明：安装后首次进入会自动清掉已损坏的虚妄文件；下次真正命中虚妄词后才会可展开。

# App icon — kers（3.2.1）

## 设计

| 元素 | 说明 |
|------|------|
| 底色 | 浅粉 ↔ 白渐变椭圆 |
| 文字 | 整体居中；手写粗细变化（起笔细、行笔粗） |
| **k** | 第一笔竖画为曲线且更长，非直线 |
| **ke** | 连笔草书偏行书 |
| **rs** | 位于字母 **e** 右上角 |
| 边框 | 极淡浅蓝细描边 |

## 构建说明

- `minSdk = 26`，使用 Adaptive Icon（`mipmap-anydpi-v26`）即可。
- **勿**在 `mipmap-*dpi` 放入损坏的 PNG（会导致 AAPT `file failed to compile`）。

版本：**3.2.1**（versionCode 3201）
